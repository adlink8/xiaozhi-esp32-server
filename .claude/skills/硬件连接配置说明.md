## 四、服务器启动说明

### 4.1 启动步骤

**步骤 1：停止现有服务器进程**

```bash
pkill -f "python3 app.py"
```

**步骤 2：激活虚拟环境**

```bash
source /home/li/xiaozhi/xiaozhi-esp32-server/venv/bin/activate
```

**步骤 3：启动服务器**

```bash
cd /home/li/xiaozhi/xiaozhi-esp32-server/main/xiaozhi-server
source ../../venv/bin/activate
python3 app.py
```

**步骤 4：后台运行（可选）**

```bash
cd /home/li/xiaozhi/xiaozhi-esp32-server/main/xiaozhi-server
source ../../venv/bin/activate
nohup python3 app.py > /dev/null 2>&1 &
```

### 4.2 进程管理

## 五、ESP32 设备连接步骤

### 5.1 设备配网

1. 确保 ESP32 设备已通电
2. 设备启动后会自动尝试连接 WiFi
3. 如果设备未连接 WiFi，需要通过以下方式配网：
   - 使用蓝牙配网（如果支持）
   - 使用 SoftAP 配网模式
   - 通过串口发送配网信息

### 5.2 配置设备连接服务器地址

在智控台中配置或直接在设备固件中设置：

```
WebSocket 地址：ws://192.168.1.105:8100/xiaozhi/v1/
```

### 5.3 验证连接

1. 启动服务器后，观察日志输出
2. 按下 ESP32 设备的唤醒按钮
3. 说出唤醒词（如"你好小智"）
4. 观察服务器日志中是否有设备连接记录

## 六、配置文件说明

### 6.1 配置文件优先级

系统会按以下优先级读取配置：

1. `data/.config.yaml`（最高优先级）
2. `config.yaml`（基础配置）

### 6.2 推荐做法

- **开发环境**：修改 `data/.config.yaml`，避免覆盖主配置文件
- **生产环境**：直接修改 `config.yaml`

### 6.3 本地开发模式配置

如果在本地开发模式运行（不使用智控台），需要确保 `data/.config.yaml` 包含：

```yaml
read_config_from_api: false
server:
  auth_key: local-dev-auth-key
```

## 七、常见问题排查

### 7.1 设备无法连接

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 连接超时 | IP 地址错误 | 确认服务器 IP 与设备配置的 IP 一致 |
| 拒绝连接 | 端口被占用 | 检查端口 8100 是否被其他程序占用 |
| 认证失败 | auth_key 不匹配 | 检查设备和服务器的 auth_key 配置 |

### 7.2 服务器启动失败

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 模块未找到 | 依赖未安装 | `source venv/bin/activate && pip install -r requirements.txt` |
| 端口被占用 | 端口已被使用 | `lsof -i :8000` 查看并停止占用进程 |
